# 🚀 우주공부선 (Space Study Ship)

**공부한 시간이 연료가 되어 우주를 탐험하는 게이미피케이션 Todo + Timer 앱**

할 일과 타이머만으로는 쌓인 기록이 눈에 보이는 보상이 되지 않습니다.<br />
그래서 공부를 게임처럼 — 공부한 시간은 연료가 되고, 연료로 행성과 지역을 하나씩 열어 갑니다.
